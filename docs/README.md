# Mika JP ドキュメント

Mika JPは、[Wang Zan氏のMika](https://github.com/wangzan101/Mika)を日本語向けに調整したフォークです。導入手順は[日本語の導入ガイド](setup-guide.ja.md)が正本です。上流MikaのAPKとは別のアプリで、アプリIDは `jp.studioyebisu.mika` です。

## 初めて使う

| ドキュメント | 内容 |
| --- | --- |
| [Mika JPの導入](setup-guide.ja.md) | このフォークのインストール、モデル接続、動作確認 |
| [モデルの設定](models.md) | APIキーやアカウントによる接続、モデルの役割、ローカルモデル |
| [スマホ操作の設定](setup-guide.md) | 無線デバッグのペア設定、ユーザー補助、USBによるヘルパー起動 |
| [確認モードと自律モード](modes.md) | お金を使う操作の確認と、本人に引き継ぐ操作 |

会話、ウェブ閲覧、ファイル処理だけなら、スマホ操作の設定は省略できます。
