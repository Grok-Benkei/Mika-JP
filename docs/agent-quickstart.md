# PCのAIエージェント向け接続手順

Mika JPのPC用ツールを導入し、接続だけを確認する手順です。スマホへの導入がまだなら、先に[AIアシスタントと導入する](install-with-agent.md)を使ってください。詳しい手順は[PC用ツールの導入](computer-install.md)と[CLI](cli.md)にあります。

## 1. このフォークのソースを使う

スマホに入れたMika JPと同じ版のソースを、このフォークの[リリース](https://github.com/yebisu0529-ship-it/Mika-JP/releases)のソースアーカイブ、または対応するチェックアウトから用意します。上流Mikaのリリースやタグで代用しません。PC用ツールを入れてもスマホのAPKは更新されません。

## 2. スキルまたはCLIを導入する

スキルに対応したエージェントは、このフォークの `tools/mika` フォルダー全体をスキルディレクトリへコピーします。保存先はエージェントの案内に従い、`<スキルディレクトリ>/mika/SKILL.md` となるようにします。同梱の `scripts/` も必要です。

```sh
python3 <スキルディレクトリ>/mika/scripts/mika_cli.py --version
```

Windowsは `python3` を `py -3` に置き換えます。新しいエージェントセッションでスキルが認識されることも確認してください。以後の `mika` は、スキルだけを導入した場合はこのスクリプトの呼び出しに置き換えます。

スキルを使わずターミナルから使う場合は、フォークのルートでCLIを導入します。

```sh
pipx install ./tools/mika
mika --version
```

PCに既存の `mika` コマンドがある場合は、スキルがそちらを優先するため、版と導入元を確認してください。

## 3. 指定された方法で接続する

既存の依頼とスマホ側の設定に従います。接続方法が分からず判断できない場合は、一度確認します。対象端末を勝手に変更しません。

USBまたは接続済みの無線ADBでは、PCからの利用が依頼されていることを確認してから実行します。`connect` はコンピューターアクセスを有効にします。

```sh
mika devices --json
mika connect --device SERIAL --json
mika doctor --device SERIAL --json
```

複数端末がある場合は対象を決め、それ以降すべてに同じ `--device SERIAL` を指定します。`unauthorized` は本人がスマホでUSBデバッグを許可し、`offline` は接続を確認します。`connection_info` の場合はスマホをロック解除してMika JPを一度開き、同じ端末へ再接続します。

Wi-Fi・プライベートVPNでは、本人がスマホでネットワークアクセスを有効にし、指定したURLとトークンファイルを使います。

```sh
mika --url http://PHONE:8765 --token-file /path/to/private-token-file doctor --json
```

トークンはファイルから使い、その内容を表示・転載しません。公開ネットワークへ直接ポートを開きません。

## 4. 確認できた範囲を報告する

この接続確認ではスマホのタスクを送信しません。`connect`・`doctor` の成功はAPIの接続確認であり、モデルやタスクの成功を証明しません。スキルの読み込み、接続、モデル設定、実際のタスクを区別して日本語で報告します。

実際のタスク確認も依頼されている場合は、その範囲内で[タスクコマンド](cli.md#任务命令)を使い、最終状態と結果を確認してください。APIキー、トークン、認証情報は報告に含めません。
