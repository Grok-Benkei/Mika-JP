# よくある質問

Mika JPの導入は[日本語の導入ガイド](setup-guide.ja.md)、スマホ操作の各段階で困った場合は[スマホ操作の設定](setup-guide.md#トラブルが発生した場合)を参照してください。

## 導入と対応端末

**会話・ウェブ・ファイル処理だけでも無線デバッグのペア設定は必要ですか？**

不要です。APKをインストールしてモデルを設定すれば使えます。無線デバッグとユーザー補助はスマホのアプリ操作に必要です。会話・ウェブ・ファイル処理はAndroid 11以降に対応し、Linux実行環境はarm64端末向けです。

**Android 14以降を推奨する理由は？**

スマホ操作はAndroid 12以降で使えます。ただしAndroid 12・13では、背景画面での操作がメイン画面の入力フォーカスへ影響する場合があります。Android 14以降では背景画面が独立したフォーカスを持つため、メイン画面で入力しながら使いやすくなります。

**自分の端末で動くか確認できますか？**

「設定 › 復旧と修復 › 互換性チェック」を実行してください。Mika JPのテスト画面などで読み取りや操作を確認します。モデルを使った実際のタスクが成功したこととは別の検査です。結果を報告する場合は、内容を確認してから[端末の互換性報告](https://github.com/yebisu0529-ship-it/Mika-JP/issues/new?template=device-report.yml)へ送信してください。

**APKはどこから入手・更新しますか？**

このフォークは開発版です。公開リリースがない間は[ローカルビルド](../README.md#ビルド)を使います。Mika JPの更新元は[このフォークのリリース](https://github.com/yebisu0529-ship-it/Mika-JP/releases)で、上流MikaのAPKは別アプリです。公式Mikaを削除したり、そのデータを消したりする必要はありません。

## スマホ操作

**無線デバッグが勝手に無効になります。**

AndroidではWi-Fiの切断や再起動で無効になる場合があります。「設定 › 復旧と修復」の自動復旧設定と、必要なシステム設定の変更許可を確認してください。初めて使うWi-Fiでは、本人がシステムの無線デバッグを開き、そのネットワークを許可する必要があります。接続できない場合は[設定ガイド](setup-guide.md)の接続・再ペア設定の手順を確認してください。

**無線デバッグが見つかりません。**

メーカーによっては利用できません。PCからUSBとadbでヘルパーを起動できます。[USBによる起動](setup-guide.md#另一种办法用电脑启动usb-数据线)を参照してください。この方法だけを使う場合、スマホの再起動後は起動コマンドを再実行します。

**ユーザー補助が無効になります。**

システムがサービスを停止する場合があります。復旧設定が有効でヘルパーが使える場合は、自動での復旧を試みます。復旧しないときは、スマホのユーザー補助設定でMika JPを確認してください。

**画面を読めない、撮影できないことがあります。**

決済やパスワード入力など、撮影が禁止された画面は読み取れません。本人へ操作を引き継ぎます。操作を返しただけでは完了とはせず、戻った画面で結果を確認します。

## モデルとPCからの利用

**自分のPCやLAN上のモデルを使えますか？**

使えます。プロバイダーのカスタム設定でスマホから到達できるアドレスを指定します。メインモデルにはツール呼び出しへの対応が必要です。[モデルの設定](models.md)を参照してください。

**APIキーなしでも使えますか？**

対応するサービスではアカウントログインを利用できます。契約や利用枠は各サービスの条件に従います。現在アプリに表示される接続方法と[モデルの設定](models.md)を確認してください。

**PCのAIエージェントからタスクを渡せますか？**

CLIとスキル、またはMCPで接続できます。通常は一つ選べば十分です。[PCからMika JPを使う](computer.md)を参照してください。接続を確認するだけではタスクは送信されません。

## 言語とプライバシー

**表示言語を変更できますか？**

Mika JPは日本語専用です。Androidの画面、CLIの会話画面、リレーのウェブ画面は、端末やブラウザの言語にかかわらず日本語で表示します。AIの説明・質問・タイトル・学習内容も日本語にします。引用原文、コード、固有名詞、実際の画面ラベルなどは、正確さのために原文を保持する場合があります。

**データはどこへ送られますか？**

モデルに必要な発言・画面・ファイルの内容は、設定したモデル提供元へ送信されます。APIキーやメモリなどは端末内に暗号化して保存し、会話や実行記録も端末に保存します。ブラウザや操作先のサービスとの通信、任意のセルフホストゲートウェイも含め、[免責事項とデータプライバシー](disclaimer.md)を確認してください。
