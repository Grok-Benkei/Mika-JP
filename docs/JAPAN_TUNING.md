# 日本向け調整の記録

2026-11-03。所有者: Studio Yebisu。段階: 開発版。目的はGalaxy上で日本語を標準としてMikaを試すこと。原作のリリースとは別に扱う。

## 変更範囲

| 対象 | 調整 |
|---|---|
| アプリ識別 | Mika JP / jp.studioyebisu.mika。公式版と併存 |
| 言語 | 日本語専用。端末や過去のアプリ言語に依存せず、表示と既定リソースを日本語に固定 |
| OCR | 同梱の日本語・ラテン文字モデル。中国語OCR専用依存を日本語用へ変更 |
| 依頼例 | LINE、X、日本の求人、YouTube、アラーム |
| AI指示 | 日本語の指示・回答・案内、実際の端末時刻、地域・通貨・住所の区別 |
| 回答の言語 | 日本語での再回答を要求し、それでも別言語のままなら日本語の停止理由を返す |
| 学習 | 日本語のメモリ、補足知識、5見出しの個人スキル。旧見出しも読込み可能 |
| 失敗時の案内 | モデル接続、上限、再試行、操作停止の日本語 |
| 操作判定 | 日本語の送信、投稿、購入、決済、削除、円表示と認証画面 |
| 内蔵知識 | 既存アプリ・サイトの日本語案内と、日本向けの追加項目 |
| サポート | フォークのGitHub Issues。原作へのクレジットを保持 |
| 更新 | フォーク自身のリリースだけを確認。上流のAPKで上書きしない |

画面、エラー、診断、AIへの説明文とコードのコメントを日本語に揃える。JSONキー、ツール名、列挙値、パッケージ名、ドメイン名、APIの識別値、画面からの引用原文は動作に必要なデータとして扱う。中国語アプリの正式名・別名、画面を認識する辞書、都市コード表、外国語の画面を検証するテスト入力にも原文が必要になる。ユーザー向けの案内文と照合用データは区別する。

## 接続先の根拠

新規接続先にはキーや認証状態を移行しない。

- [Qwenのリージョン別Base URL](https://www.alibabacloud.com/help/en/model-studio/base-url): 国際向け候補はシンガポールの共有エンドポイント。東京のワークスペース固有ホストは本人がカスタムで指定する。
- [KimiのQuickstart](https://platform.kimi.ai/docs/get-your-api-key): 国際向けapi.moonshot.ai/v1。
- [MiniMaxの互換API](https://platform.minimax.io/docs/api-reference/text-openai-api): 国際向けapi.minimax.io/v1。

中国本土向けの既存接続先は追加のリージョン候補として保持する。モデルの実APIによる課金を伴う推論は、本人の接続設定なしに実行しない。

## 確認方法

1. knowledgeIndexで見出し、パッケージ、ドメイン、相互参照、本文長を検査する。
2. 変更した操作判定、知識検索、学習、画面判定をJVMテストで確認する。
3. 日本語プロンプトとスナップショットの差分を確認する。
4. APKをビルドし、実機で日本語の固定、端末や旧設定の言語に影響されないこと、日本語OCRを確認する。
5. スマホ操作ヘルパーと互換性チェックを確認する。
6. AI接続後の実際のタスクは本人の認証後に確認する。

全アプリのログイン状態や全機能を検証したとは扱わない。実機で読めていない画面のラベルや座標を内蔵知識で固定しない。

## 検証結果
