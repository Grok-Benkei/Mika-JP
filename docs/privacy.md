# データと権限の取扱い

Mika JPはStudio Yebisuが日本向けに調整したMikaのフォークです。利用するAIサービスと接続先は本人が設定します。

## モデルへ渡す情報

依頼内容、会話、選択した添付ファイル、作業に必要な画面の画像・テキストや操作結果を、設定したAIサービスへ送ります。提供先の保存・学習・利用条件は各サービスの規約に従います。Mika JPがすべての接続先について同じデータ管理を保証するものではありません。

中国系サービスは海外リージョンも含め既定の候補から除外します。本人が明示した接続やURLへのアクセスは別です。ブラウザーで開いたサイト、任意のMCPサーバーやリレーには、それぞれの処理に必要な情報が渡ります。

## 端末に保存する情報

会話、ファイル、作業記録、メモリ、スキル、接続設定を端末内に保存します。APIキーやChatGPTの接続情報にはAndroid Keystoreを用いる暗号化保存処理を使います。端末から送信する場面、本人がコピー・共有した内容、root権限を持つ他のプログラムまで保護する保証ではありません。

詳細な記録・OTLPの送信、PC接続、リレー、サンドボックスのネットワークは、それぞれの設定と本人の選択に従います。診断結果や不具合報告は、内容を確認してから本人が共有します。

## 権限

ユーザー補助と操作ヘルパーはアプリの読み取り・操作、通知は進行や本人への確認、マイクは音声入力、ファイルへのアクセスは本人が選んだファイルの処理に使います。ブラウザーやファイル処理だけの場合と、スマホのアプリ操作の場合では必要な設定が異なります。

root取得済み端末の機能は通常のアプリ操作とは別の強い許可で、既定では無効です。許可すると他のアプリのデータやシステム領域も扱えます。[確認モードと自律モード](modes.md)を確認して設定してください。

## 保存内容を整理する

会話、メモリ、サイトのログインや接続先はアプリの該当設定から整理できます。サービス側の保存データやアカウントの削除は、そのサービスで手続きしてください。認証情報をIssuesやチャットへ貼り付ける必要はありません。
