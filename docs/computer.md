# PCからMika JPを使う

PCのAIエージェントやターミナルから、スマホ上のMika JPへタスクを渡せます。進捗の確認、質問への回答、追加指示、停止もできます。PCは目的を伝え、スマホ上のMika JPが手順を考えて実行します。

スマホには、このフォークのAPKをインストールし、一度起動してモデルを設定してください。現在の導入方法は[Mika JPの導入](setup-guide.ja.md)と[ローカルビルド](../README.md#ビルド)を参照してください。上流MikaのリリースAPKはMika JPではありません。会話・ウェブ・ファイル処理はAndroid 11以降、アプリ操作はAndroid 12以降に対応します。アプリ操作には[スマホ操作の設定](setup-guide.md)も必要です。

## 1. 使う入口を選ぶ

どの入口もスマホ上の同じタスクサービスへ接続します。通常は一つ選べば十分です。複数のクライアントを使う場合は併用できます。

| 用途 | 選ぶもの | 手順 |
| --- | --- | --- |
| コマンドとスキルを使えるAIエージェントに任せる | スキル。同梱CLIがあるため、別のCLIやMCP設定は不要 | [スキルの導入](computer-install.md#skill安装) |
| ターミナルやスクリプトから操作する | CLI。`mika` コマンドを使う | [CLIの導入](computer-install.md#cli安装)、[コマンド一覧](cli.md) |
| MCP対応のクライアントから使う | MCP。スマホがMCPサーバーになる | [MCPでの接続](mcp.md) |

## 2. 接続方法を選ぶ

CLI・スキルとMCPは、同じ接続方法の設定を共有します。

| 項目 | USB／接続済みの無線ADB | Wi-Fi／プライベートVPN |
| --- | --- | --- |
| 前提 | PCにAndroid platform-toolsがあり、`adb devices` に対象が `device` と表示される | PCとスマホが同じWi-FiまたはプライベートVPNに接続している |
| 有効にする方法 | CLIの `connect`、またはMCP用の起動手順 | スマホの「設定 › コンピューターに接続」でネットワークアクセスを本人が有効にする |
| 接続範囲 | スマホのローカルポートをADBでPCへ転送する | LANとプライベートVPNのアドレスのみ。公開IPからの接続は受け付けない |

USBとネットワークには、それぞれ別のスイッチとトークンがあります。両方を有効にすることもできます。直接接続はHTTPなので、信頼できるPCとネットワークで使用してください。トークンは他人に渡さないでください。

スマホ内のヘルパーを無線デバッグでペア設定することと、PCを無線ADBで接続することは別です。スマホ側のペア設定だけでは、PCのADB接続やコンピューターアクセスは有効になりません。

公開ネットワーク越しに接続する場合は、任意で[セルフホストのゲートウェイ](dev/remote-mcp.md)を利用できます。本人によるペア設定とアクセス許可が必要です。ゲートウェイは転送内容を読めるため、信頼できるものを使ってください。

## 3. 導入・接続する

- CLIまたはスキル: [導入ガイド](computer-install.md)の後に[接続とタスクコマンド](cli.md)を確認します。
- MCP: [MCPガイド](mcp.md)のUSBまたはネットワークの手順を使います。
- PCのAIアシスタントにスマホへの導入も頼む: [AIアシスタントと導入する](install-with-agent.md)を使います。設定済みのスマホへ接続するだけなら、再インストールは不要です。

接続に成功しても、モデルや実際のタスクが動作したとは限りません。接続確認とタスクの完了確認を分けて扱います。支払い、承認、本人だけができる操作はスマホで対応します。PCから質問に回答する操作で、これらを代行することはできません。

## ブラウザの会話画面（`mika ui`）

スマホを接続して `mika ui` を実行すると、PCのブラウザに日本語の会話画面が開きます。ブラウザの言語設定には依存しません。タスクの開始、進捗の表示、質問への回答、追加指示、停止に対応します。本人への引き継ぎはスマホで対応してください。

直近50件のリモートタスクを会話ごとに表示します。終了後に同じ会話へ入力すると続きを依頼でき、新しい会話も作成できます。各ターンの過程表示には、この画面で観測した状態と進捗が表示されます。下書きは保持され、ブラウザが背景にある間は更新を一時停止します。

タスク回復に対応するスマホでは、送信前にリクエストIDを記録します。切断で応答を失った場合は、再接続後にそのIDで元のタスクを探します。「元のタスクを検索」で見つからず、再送する場合は同じIDを使います。確認は同じタブの再読み込み後も引き継がれます。確認できた、再送が成功した、または本人が確認を中止するまで記録を保持します。

- 複数の端末がある場合は画面上で選ぶか、`mika ui --device SERIAL` で指定します。
- ネットワーク接続には `--url` と `--token-file` を使います。
- スキルだけを導入した場合は `python3 <スキルディレクトリ>/mika/scripts/mika_cli.py ui` を使います。Windowsでは `python3` を `py -3` に置き換えます。
- ブラウザを自動で開かない場合は `--no-open` を指定し、表示されたURLを同じPCのブラウザで開きます。
- サーバーは `127.0.0.1` のランダムなポートだけで待ち受けます。URLには今回の画面へアクセスする秘密値が含まれるため、共有しないでください。
- Ctrl+Cで会話画面を閉じても、スマホで開始済みのタスクは継続します。停止にはタスクの停止操作を使います。
