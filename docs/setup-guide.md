# スマホ操作の設定

Mika JPにAndroidアプリを操作させるための手順です。APKの導入とモデル設定は[Mika JPの導入](setup-guide.ja.md)を参照してください。アプリIDは `jp.studioyebisu.mika` で、上流Mikaとは別アプリです。

会話、ウェブ閲覧、ファイル処理だけなら、この設定は省略できます。アプリ操作はAndroid 12以降に対応し、背景画面の入力が独立するAndroid 14以降を推奨します。

## 始める前に

Mika JPは、別の背景画面でアプリを開いて操作します。そのために、Androidの無線デバッグで同梱のヘルパーを起動します。スマホだけでペア設定でき、通常は一度の設定で済みます。無線デバッグが使えない端末では、[USBで起動する方法](#另一种办法用电脑启动usb-数据线)もあります。

無線での設定中はWi-Fiへの接続が必要です。インターネットへ到達できないWi-Fiでも構いません。Androidやメーカーによって、設定名と場所は異なります。見つからない項目はシステム設定の検索を使ってください。

開発者向けオプションでは、この手順で必要な項目だけを変更します。データ消去、再フォーマット、初期化を求められた場合はキャンセルしてください。「16 KBページサイズで起動」など、無関係な項目は変更しません。Galaxyの自動ブロッカーなどが操作を止める場合も、表示内容と変更の影響を確認してから本人が判断してください。

## ウィザードを開く

初回設定、またはMika JPの設定にあるスマホ操作の項目から、設定ウィザードを開きます。未設定のままアプリ操作を依頼した場合にも案内が表示されます。

ウィザードは6段階です。完了した項目は自動でチェックされ、現在の項目から対応するシステム設定を開けます。設定後は戻る操作でMika JPへ戻ってください。

端末によっては、有効にしたスイッチをMika JPが読み取れません。実際に有効になっていることを確認し、その段階の手動で次へ進むボタンを使ってください。ペア設定と接続は、最後に実際の成功を確認します。以前の段階を開き直してやり直すこともできます。

## 1. 開発者向けオプションを表示する

1. スマホの設定で端末情報を開きます。Galaxyでは通常「端末情報 › ソフトウェア情報」です。
2. 「ビルド番号」を7回続けてタップします。端末によってはバージョン情報の中にあります。
3. 画面ロックの認証を求められた場合は、本人がスマホで入力します。
4. 開発者向けオプションが有効になった表示を確認し、Mika JPへ戻ります。

すでに有効という表示が出た場合は、そのまま戻って構いません。反応しない場合は、ビルド番号を間を空けずにタップしているか確認してください。

## 2. USBデバッグを有効にする

ウィザードから開発者向けオプションを開き、USBデバッグを有効にします。確認画面が出たら内容を確認して許可し、Mika JPへ戻ります。この時点でUSBケーブルは不要です。

USBデバッグは、ヘルパーがWi-Fi切断後も動作を続けるために必要です。スマホ操作を使う間は有効にしておきます。無効にすると、アプリ操作ができなくなります。

## 3. ユーザー補助を設定する

ウィザードでは、この段階をスキップして、ペア設定後にMika JPがユーザー補助を有効にする方法を選べます。復旧設定のユーザー補助の自動有効化は、既定で有効です。スキップした場合、次のペア設定では本人が6桁のコードを通知に入力します。

すでにMika JPのユーザー補助が有効なら、ペア設定画面のコードをMika JPが読み取れるため、入力を省略できます。

手動で有効にする場合は、システムのユーザー補助設定でMika JPを選びます。ストア外から導入したアプリでは「制限付き設定」で止められる場合があります。その場合は次の手順を使います。

1. 一度有効化を試し、システムの制限表示を確認します。
2. Mika JPのアプリ情報を開き、右上のメニューに「制限付き設定を許可」があれば選びます。
3. ユーザー補助設定へ戻り、Mika JPを有効にします。

このメニューは、システムが一度制限した後に表示される場合があります。権限の許可をほかのアプリが妨げていると表示されたら、チャットの吹き出しなど、ほかのアプリのオーバーレイを閉じて試してください。

## 4. 無線デバッグを有効にする

Wi-Fiへ接続してから、開発者向けオプションの無線デバッグを有効にします。ネットワークごとの許可画面が出たら内容を確認して許可します。今後もそのWi-Fiで自動復旧させる場合は、そのネットワークを常に許可する選択肢を使います。

有効にしてもすぐ無効になる場合は、Wi-Fi接続とネットワークの許可を確認してください。スイッチは有効なのにウィザードが進まない場合は、実際の設定を確認してから手動で次へ進みます。無線デバッグ自体がない端末では、[USBでの起動](#另一种办法用电脑启动usb-数据线)を使ってください。

## 5. ペア設定コードを使う

ペア設定コードは、システムのペア設定ウィンドウが開いている間だけ有効です。別のアプリへ切り替える、戻る、画面をロックするなどで閉じると無効になります。コードはチャットへ送らず、Mika JPの通知から入力してください。

まずMika JPの通知を許可します。通知が無効な場合や、ペア設定用の通知チャンネルが無効な場合はウィザードに案内が出ます。画面上部へ通知を出す設定が無効でも、通知欄を下ろせば入力できます。

システムの無線デバッグの項目名をタップして詳細を開き、ペア設定コードを使う項目を選びます。6桁のコードと、ペア設定用のIPアドレス・ポートが表示されます。

### ユーザー補助が有効な場合

ペア設定ウィンドウを表示したまま数秒待ちます。Mika JPがコードを読み取り、ペア設定を試みます。成功するとウィンドウが閉じます。

### ユーザー補助をスキップした場合

1. ペア設定ウィンドウを表示したまま、6桁のコードを確認します。
2. Mika JPのペア設定通知を開きます。通知が上部に出なければ、通知欄を下ろします。通知欄を開いてもペア設定ウィンドウは閉じません。
3. 通知の入力欄に6桁のコードを入れ、送信します。
4. ペア設定の成功表示を確認し、Mika JPへ戻ります。

未入力の場合は通知が最大3回表示されます。入力が6桁になっていない場合やコードが違う場合は、通知の案内を確認してください。期限切れになったら、システムでペア設定ウィンドウを開き直し、新しいコードを使います。

通知を使えない場合は、ウィザードの手動入力を使えます。ただしMika JPへ切り替えるとウィンドウが閉じるため、分割画面で両方を表示してください。ウィンドウを自動検出できない場合は、そこに表示されたペア設定用ポートの入力も求められます。

この段階は、手動で完了扱いにして進めることはできません。実際のペア設定の成功が必要です。

## 6. 接続を確認する

ペア設定後、Mika JPがヘルパーへ接続します。スマホ操作の準備ができた表示になれば完了です。手順3をスキップしていた場合は、ユーザー補助の有効化も試みます。

無線デバッグの接続先は、以前のポート、システムから得た情報、同じネットワークでの通知などから探します。見つからない場合は、端末自身のポートを最大10秒ほど調べます。同じWi-Fiにあるほかの端末は調べません。

自動検出できない場合は、システムの無線デバッグの詳細にあるIPアドレスとポートを確認し、ポート番号を入力します。たとえば `192.168.1.5:41235` なら `41235` です。これは手順5のペア設定ウィンドウのポートとは別です。無線デバッグを入れ直すと番号が変わる場合があります。

失敗した場合は、ウィザードが示す段階へ戻って確認します。途中で終了し、後から設定で再開することもできます。

## 別の方法: USBでヘルパーを起動する

無線デバッグが使えない場合は、Android platform-toolsを導入したPCから起動できます。開発者向けオプションとUSBデバッグを有効にし、データ通信ができるケーブルで接続します。USBデバッグの許可はスマホで本人が行ってください。

対象が `adb devices` に `device` と表示されることを確認します。複数端末がある場合は、以後のすべてのadbコマンドに `-s SERIAL` を付け、同じ端末を指定してください。

```sh
adb shell am start -n jp.studioyebisu.mika/com.wangzan101.mika.ui.MainActivity
adb shell sh /sdcard/Android/data/jp.studioyebisu.mika/files/usb-start.sh
```

Mika JPを開くと起動ファイルが用意されます。ファイルがない場合は一度開き、少し待ってから同じコマンドを試してください。起動ログだけでなく、Mika JPの設定でスマホ操作が利用可能になったことを確認します。

- ケーブルを外してもヘルパーは動作を続けます。
- この方法だけを使う場合、スマホを再起動した後は、Mika JPを開いて同じコマンドを再実行します。
- 無線デバッグのペア設定も済んでいて自動復旧が成功する場合は、再起動後にその方式で復旧できます。
- Mika JPの更新後も、一度アプリを開いてから起動し直してください。
- ヘルパー起動用ファイルの内容をチャットやログへ貼り付けないでください。未接続時には一度限りの接続情報が含まれます。
- USBで起動済みなら、ウィザードは無線の段階をスキップ扱いにできます。動作中に改めてペア設定を強制する必要はありません。

## 設定後の復旧と解除

USBデバッグは、スマホ操作を使う間は有効にしておきます。無線デバッグはAndroidが無効にする場合がありますが、ヘルパーの再起動が必要なときに使うもので、常時有効でなくても動作する場合があります。

「設定 › 復旧と修復」の無線デバッグの自動有効化と再起動後の復旧は、既定で有効です。必要な権限とWi-Fiの許可がある場合に復旧を試みます。新しいWi-Fiでは、本人が一度システム上で許可してください。自動復旧に失敗したときは設定の修復・再ペア設定を使います。

使わなくなった場合は、Mika JPのスマホ操作設定でペア設定を解除します。システムの無線デバッグにあるペア設定済み端末からMikaを削除する方法もあります。

## トラブルが発生した場合

| 症状 | 確認すること |
| --- | --- |
| 開発者向けオプションが見つからない | ビルド番号を7回タップしたか確認し、システム設定で項目を検索します。 |
| 無線デバッグがすぐ無効になる | Wi-Fi接続と、そのネットワークでの無線デバッグの許可を確認します。 |
| ペア設定通知がない | Mika JPの通知権限とペア設定用通知を確認します。通知欄を下ろすか、分割画面での手動入力を使います。 |
| コードが違う・期限切れ | ペア設定ウィンドウを開き直し、新しい6桁のコードを入力します。入力中にウィンドウを閉じないでください。 |
| ペア設定後に接続できない | 無線デバッグとWi-Fiを確認して再試行します。検出できない場合は接続用ポートを入力します。 |
| スイッチは有効なのに進まない | 一部端末では読み取れません。実際の設定を確認し、その段階の手動継続ボタンを使います。 |
| 新しいWi-Fiで復旧しない | システムの無線デバッグを本人が開き、そのネットワークを許可します。 |
| ペア設定が失効した | ウィザードで再ペア設定します。 |
| USB方式で再起動後に止まる | Mika JPを開き、上記の `usb-start.sh` を再実行します。 |
| ユーザー補助が制限される | 手順3のスキップ、またはシステムの制限付き設定の手順を確認します。 |
| ペア設定後もユーザー補助が無効 | 復旧設定の自動有効化を確認し、失敗する場合はシステム設定で有効にします。 |
| 権限の許可をほかのアプリが妨げている | ほかのアプリの吹き出し・フローティング表示を閉じて試します。 |

解決しない場合は、ウィザードの診断情報を確認してから[このフォークへ報告](../.github/CONTRIBUTING.md)してください。診断はバージョン、機種、段階ごとの状態、最近の失敗理由などを扱います。共有前に本人が内容を確認し、APIキーや会話・画面の内容を添付しないようにしてください。

## 設定後の互換性チェック

接続できてもアプリを開けない、タップや入力が動かない場合は、「設定 › 復旧と修復 › 互換性チェック」を実行します。確認中はそのページにとどまってください。

Mika JPのテスト画面とシステム設定を使って、読み取り、タップ、入力、スクロール、戻る操作を確認し、内蔵ブラウザや実行環境も調べます。このチェックはモデルAPIを使わず、他社アプリへの操作や設定変更、外部ネットワーク通信を行いません。

結果は成功、一部利用可能、失敗、スキップなどに分かれ、失敗時には理由と次の対応が表示されます。報告する場合は内容を確認し、[端末の互換性報告](https://github.com/yebisu0529-ship-it/Mika-JP/issues/new?template=device-report.yml)へ本人が送信します。互換性チェックの成功と、モデルを通した実際のタスクの成功は別です。
