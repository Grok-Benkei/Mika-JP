# 確認モードと自律モード

Mika JPが代わりに作業するとき、どの段階で確認を求めるかを切り替えます。設定の開発者向け項目にある自律モードを無効にすると確認モード、有効にすると自律モードです。

| モード | 動作 |
| --- | --- |
| 確認（既定） | お金を使う直前に確認します。注文や、支払額が表示されたページでの確定・送信などが対象です。カードに場所・商品・金額を示し、今回だけの同意を求めます。支払いそのものは本人が行います。依頼されたメッセージ送信、投稿、フォーム提出、削除、設定変更は直接実行します。 |
| 自律 | お金を使う手順も、事前の確認を求めずに進めます。連続した操作の間隔などは維持します。 |

切り替えは以後のタスクに反映されます。実行中に確認から自律へ変更した場合も、その後の手順へ適用されます。

どちらのモードでも、ログイン、認証コード、支払いの暗証番号など、本人だけが扱える段階は引き継ぎます。情報が不足している場合や、同名の連絡先から相手を選ぶなど本人の判断が必要な場合は質問します。

予約タスクなど本人がその場にいないタスクは、確認モードで支出の確認が必要になると、その手順を実行せずに結果を報告します。ほかの実行可能な部分は続けます。

PCから受け付けたタスクの確認・支払い・本人への引き継ぎは、スマホで対応します。PCの回答コマンドで同意や決済を代行することはできません。

## rootコマンドを許可した場合

root取得済みの端末で、本人がrootコマンドの実行を許可した場合にだけ使える機能です。通常のアプリ操作とは別の許可で、既定では無効です。root取得済み端末での実機検証は未実施です。

確認モードでは、変更・削除を行うrootコマンドを実行前に確認します。カードに表示したコマンドだけを一度許可します。本人が不在のタスクや、確認に対応できない実行元では、この種のコマンドを実行しません。読み取り専用と判定できる狭い範囲のコマンドは直接実行します。

自律モードでは、許可済みのrootコマンドも確認を省略します。root権限では他のアプリのデータやシステム領域も扱えるため、自律モードとroot許可を同時に有効にする意味を確認してください。ログイン、認証、支払いなど本人が行う段階や、アプリのアクセス制限を回避するための機能ではありません。設定方法は[導入ガイド](setup-guide.ja.md)を参照してください。

依頼した操作と実行結果を確認してください。重要な作業では確認モードを使い、[免責事項](disclaimer.md)も読んでください。
