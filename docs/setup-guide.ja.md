# Mika JPの導入

Mika JPは日本向けに調整した別アプリです。公式Mikaをアンインストールしたり、データを削除したりする必要はありません。

## 1. インストール

このフォークのAPKをAndroidで開くか、PCにUSB接続してadb install -rでインストールします。アプリ名は「Mika JP」、パッケージ名はjp.studioyebisu.mikaです。上流MikaのAPKとは異なります。

Galaxyの自動ブロッカーがインストールやUSBデバッグを止める場合があります。表示された内容と変更する設定を確認してから判断してください。導入に必要な設定だけを変更します。

## 2. AIを接続する

初回画面、または「設定 › モデル」からプロバイダーを選びます。ログインやAPIキーの入力はスマホ上で行います。認証情報をチャットや不具合報告へ貼り付けないでください。

- メインモデルにはツール呼び出しへの対応が必要です。
- 音声入力はまず端末の音声認識を使えます。日本語版では日本語を初期設定にします。
- Qwen、Kimi、MiniMaxの国際向けと中国本土向けは別の接続先です。対応するリージョンのキーを選びます。
- 「テストして保存」は実際に接続します。API利用料やアカウントの利用枠は各サービスの条件に従います。

## 3. アプリ操作を設定する

会話、ウェブ、ファイル処理だけなら、スマホ操作の設定を省略できます。

アプリも操作する場合は、Mika JPの「設定」からスマホ操作のウィザードを開きます。USBデバッグ、無線デバッグ、ユーザー補助、通知などの案内に従ってください。Galaxyの開発者向けオプションは通常「設定 › 端末情報 › ソフトウェア情報」のビルド番号を7回タップして表示します。案内にない開発者設定を変更しないでください。

一度の無線デバッグのペア設定で再起動後も復帰させる方式と、USBでヘルパーを起動する方式があります。ペア設定はスマホの画面で本人が行います。

USBで起動する場合、Mika JPを一度開いた後に次を実行します:
~~~sh
adb shell am start -n jp.studioyebisu.mika/com.wangzan101.mika.ui.MainActivity
adb shell sh /sdcard/Android/data/jp.studioyebisu.mika/files/usb-start.sh
~~~

このUSB方式はケーブルを外してもヘルパーが動作しますが、スマホの再起動後は同じ起動コマンドが必要です。無線ペア設定済みの復帰が成功する場合はその方式を使えます。

## 4. 互換性を確認する

「設定 › 復旧と修復 › 互換性チェック」を実行します。自己診断はモデルのAPIを使わず、Mikaのテストページとシステム設定を使います。

その後、Mika JPに「設定を開いて、Androidのバージョンを教えて」と依頼して確認できます。モデルをまだ接続していない場合は、タスク実行まで確認済みとは扱いません。

## 最初の依頼例

- 明日の朝7時にアラームを設定して
- LINEで家族に送る、帰りが遅くなる連絡の下書きを作って
- このPDFを日本語で要約して
- Amazon.co.jpと楽天市場で指定した商品の価格と送料を比較して

下書き、比較、閲覧だけの依頼で、送信や購入を行わないことも確認してください。ログイン、決済、認証など本人の操作が必要な段階は引き継ぎます。
