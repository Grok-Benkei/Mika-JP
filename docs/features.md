# Mika JPでできること

Mika JPは、依頼の目的に合わせてスマホのアプリ、内蔵ブラウザ、ファイル処理を使います。導入は[日本語ガイド](setup-guide.ja.md)、現在の調整範囲は[日本向け調整の記録](JAPAN_TUNING.md)を参照してください。原作は[Wang Zan氏のMika](https://github.com/wangzan101/Mika)です。

画面と案内は日本語専用です。端末やブラウザの言語にかかわらず、AIの説明・質問・タイトル・学習内容も日本語にします。固有名詞、コード、画面上の実際のラベル、引用原文などは正確さのために原文を保持します。

## 背景画面でアプリを操作する

Mika JPは別の背景画面でアプリを開き、文面を読み、タップ・入力・スクロールを行います。対応する操作はアプリの画面や端末側の制限に左右されるため、すべてのアプリの全機能を保証するものではありません。

会話内の小さな画面で進行状況を確認できます。表示を閉じてもタスクは続き、本人の対応が必要になるとボタンや通知で知らせます。背景画面の一覧から各タスクの使用中アプリを確認し、画面を拡大して見ることもできます。

- 同じアプリを複数タスクが使う場合は順番を待ちます。待機の上限や互いの待ち合わせを検出した場合は、その状態を返します。
- 長い一覧やチャット履歴を、画面を進めながら収集できます。
- 操作要素の文面が取れない画面では、APK同梱の日本語・ラテン文字OCRを使います。画像を読めるモデルがあれば、ボタンや入力欄を画像から探すこともできます。
- Androidの共有機能で文面をアプリへ渡せます。共有画面が開いただけでは送信済みにはせず、宛先選択と送信、結果の確認が必要です。
- アプリ選択画面、複製アプリ、別アプリへの遷移も扱います。本人の選択が必要な場合は引き継ぎます。
- ログイン、認証、支払いなど本人が扱う段階では、対象画面を本人へ渡します。戻った後に結果を読み直してから続けます。

終了後、Mika JPが開いたアプリは既定で背景に残り、最後のページを保持します。音声・動画を再生しているアプリは終了時に閉じる扱いがあります。「再生を続けて」「終わったら閉じて」などの指定があれば、その依頼に従います。

複数の会話でタスクを同時実行するには、同時実行の設定とAndroid 14以降が必要です。低メモリ端末や、追加の仮想画面を作成できなかった場合は、同時実行を一件に制限します。

## 内蔵ブラウザで調べる・操作する

背景でウェブページを開き、クリックや入力で操作します。既定ではPC向けのページを使います。ページ本文や、ページ自身が受け取ったデータを読み、ダウンロードとアップロードにも対応します。

ログイン状態は保持され、本人がサイドバーのブラウザでログインしたサイトをタスクでも使えます。同じサイトでページを進める際は間隔を空けます。アクセス制限や確認画面で止められた場合は、無理に繰り返さず、本人への引き継ぎや停止を行います。

## 今見ている画面を送る

ほかのアプリを使っている間も、フローティングカプセルから進捗、質問、結果を確認できます。開いて追加指示、回答、承認、停止を行えます。

カプセルをダブルタップすると、今見ている画面をMika JPへ送れます。送信前に一言添え、「この内容を要約して」「この返信の下書きを作って」などと依頼できます。画面を送ることと、そのアプリの自動操作を許可することは別です。撮影を禁止した画面は取得できません。

## 時刻や条件を指定して予約する

「明日の朝9時に知らせて」「毎朝、雨なら教えて」「毎週金曜日に確認して」などと依頼できます。結果は元の会話へ戻ります。予約タスクの画面から、一時停止、時刻の変更、即時実行、削除ができます。

固定のリマインダーと、調べたり操作したりするタスクは区別して扱います。日付と時刻は端末の実際のタイムゾーンを基準にし、資料や依頼で別の地域を指定した場合はその条件を使います。本人が不在のときの支出確認については[確認モード](modes.md)を参照してください。

## 実行中に指示を追加し、停止する

作業中の会話に追加・修正を送ると、次の操作へ進む前に読みます。すでに実行中の操作や完了済みの操作を取り消すものではありません。

会話の各手順や実行過程から、操作内容、入力、結果を確認できます。まだモデルに取り込まれていないメッセージは、長押しで取り消したり編集へ戻したりできます。入力欄に下書きがある場合や、画面・ウェブから選択した文面を含む場合は、編集できないことがあります。

停止後は、何を実行し、何を確認し、何が未完了かを短く報告します。その記録は次に続きを頼むときの文脈になります。停止要求を出しただけでなく、停止した状態を確認してください。

## 音声で入力する

会話の入力欄が空なら長押しで話せます。離すと文字が入力欄へ入り、編集してから送信できます。上へスライドして取り消す操作も使えます。

ほかのアプリ上のカプセルでは、長押しで話し、離すと直接送信します。実行中なら追加指示、質問待ちなら回答になります。送信前に直したい場合は、編集する操作で入力欄へ移してください。

既定では端末の音声認識を使います。対応状況や認識結果が合わない場合は、モデル設定で対応する音声の文字起こしサービスを選べます。[モデルの設定](models.md)を参照してください。外部サービスの利用には各提供元の料金や利用枠が適用されます。

## 確認モードと自律モード

既定の確認モードでは、お金を使う直前に同意を求めます。依頼された送信、投稿、削除、設定変更などは直接実行するため、閲覧や下書きだけの依頼と区別して伝えてください。自律モードは支出の事前確認も省略します。ログインや本人だけが扱える認証などは、どちらでも引き継ぎます。

PCからのタスクは、必要な承認や支払いをスマホで行います。詳しくは[モードの説明](modes.md)を参照してください。

## メモリと学習した手順を使う

本人が話した事実、好み、今後の進め方を記憶し、設定から確認・変更・削除できます。進め方の記憶は承認を待ちます。画面で見ただけの個人情報を本人の好みとして覚えず、パスワード、認証コード、カード番号なども保存しません。メモリは端末内に暗号化して保存します。

繰り返す作業は個人用スキルとして整理できます。ユーザーが依頼して作成・取り込む方法と、実際に完了した作業から学習する方法があります。保存した内容と採用状態は設定で確認してください。未確認の操作経路や今回限りの宛先・本文・金額を、恒常的な手順へ混ぜません。

## 内蔵のアプリ知識とスキルを使う

アプリやサイトに固有の注意点と、複数のアプリに共通する作業手順を同梱しています。該当するものを読み、現在の画面と照合して使います。知識に書かれていないアプリでも操作を試せますが、知識があること自体は全機能の動作保証ではありません。

現在の一覧は[ルートREADME](../README.md#内蔵知識)、追加方法は[寄稿ガイド](../.github/CONTRIBUTING.md)を参照してください。本文は [knowledge](../core/src/main/resources/knowledge/) と [skills](../core/src/main/resources/skills/) にあります。

## 複数の対象を順に処理する

依頼された条件や対象の集合に沿って、一件ずつ操作し、それぞれ結果を確かめます。操作間には間隔を空けます。サイトが上限やアクセス制限を報告した場合は止め、成功したもの、失敗したもの、未処理のものを報告します。

下書きや比較だけの依頼を、連続した送信・応募・注文の依頼として扱いません。対象や条件が不足している場合は、必要な点を確認します。

## 根拠と使用量を確認する

回答には、実際に読んだページや画面などの参照が付きます。タスクごとの実行記録から操作を確認できます。操作コマンドが成功したことと、依頼された結果が得られたことは分けて確認します。

タスクの概要では、所要時間、モデルとのやり取り、トークン使用量、最初の応答までの時間などを確認できます。設定のトークン使用量では、日・プロバイダー・モデルごとの集計を表示します。

## Linux実行環境でファイルを処理する

会話ごとに作業領域があり、Python、Node、シェルで添付やダウンロードを処理できます。成果物は共有操作でスマホの `Download/Mika` へ渡せます。作業領域へ保存しただけで、ダウンロードフォルダーへ保存済みとはしません。

この環境はarm64端末向けです。ほかの端末ではアプリの導入や会話などは使えますが、Linux実行環境は非対応になります。

ネットワークは既定で無効です。必要な場合は、ファイル・実行環境の設定でスクリプトのネットワークを有効にします。有効な場合はMika JPのネットワークプロキシ設定も適用されます。モデル、更新確認、内蔵ブラウザなどの通信設定と区別して確認してください。

設定では使用容量の確認や、会話ごとの作業ファイルの整理ができます。実行中のタスクがある会話は削除対象にできません。

## PCのAIエージェントから使う

CLIとスキル、またはMCPからタスクを渡し、進捗、質問、結果を扱えます。通常は一つ選べば十分です。CLIのブラウザ会話画面と、任意のリレーのウェブ画面も日本語で表示します。

- エージェントがスキルとコマンドを使える場合は、同梱CLIのあるスキルを導入します。
- ターミナルやスクリプトから使う場合は、CLIを導入します。
- MCP対応クライアントでは、MCPサーバーとして登録します。

選択方法は[PCからの利用](computer.md)、導入は[CLIとスキル](computer-install.md)または[MCP](mcp.md)を参照してください。PCのAIアシスタントとスマホへの導入を進める場合は[専用ガイド](install-with-agent.md)を使います。公開APKは[Mika JPのリリース](https://github.com/yebisu0529-ship-it/Mika-JP/releases)から取得し、上流MikaのAPKと区別してください。

## 必要な環境

| 機能 | 要件 |
| --- | --- |
| 導入、会話、ウェブ、ファイル処理 | Android 11以降。Linux実行環境はarm64向け |
| アプリ操作 | Android 12以降。12・13ではメイン画面の入力フォーカスへ影響する場合がある |
| 独立した背景入力、複数会話での同時操作 | Android 14以降。同時操作は設定と端末のメモリ・仮想画面の対応にも依存する |
| モデル | メインモデルはツール呼び出しへ対応。接続方法は[モデルの設定](models.md)を参照 |
| スマホ操作ヘルパー | [無線のペア設定またはUSB起動](setup-guide.md) |

## 最初に試す依頼

- 「設定を開いて、Androidのバージョンを教えて」
- 「このPDFを日本語で要約して」
- 「LINEで家族に送る、帰りが遅くなる連絡の下書きを作って」
- 「明日の朝7時にアラームを設定して」
- 「毎朝8時に天気を調べ、雨なら教えて」

アプリの名前や宛先、対象の地域、必要な確認範囲を指定すると条件を合わせやすくなります。困った場合は[よくある質問](faq.md)と[スマホ操作の設定](setup-guide.md#トラブルが発生した場合)を参照してください。
