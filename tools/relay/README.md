# 自前のリモートCLI/MCPゲートウェイ

Mika JPをインターネット越しにPCから利用するための、任意のGoゲートウェイです。利用範囲は所有者1人、スマホ1台、ゲートウェイ1プロセスです。スマホが外向きのWSS接続を作り、クライアントはゲートウェイのHTTPS `/mcp` または `/api/v1` へ接続します。スマホへのポート転送や追加のVPNアプリは不要です。

配備、ペア設定、認証情報、Nginxとの併用、切断時の扱いは[リモートCLI/MCPの開発資料](../../docs/dev/remote-mcp.md)を参照してください。利用者向けの接続方法は[PCからMikaを使う](../../docs/computer.md)にまとめています。

## 認証と表示言語

各リクエストはスマホの既存アクセストークンで認証されます。管理キー、スマホとゲートウェイのペア設定用認証情報、クライアント用アクセストークンは別々です。ペア設定を済ませてもリモートアクセスは有効にならず、スマホ上で明示的に許可する必要があります。ゲートウェイ経由の画面点灯・ロック解除も既定では無効です。

管理画面、エラー、入力チェック、確認ダイアログは日本語固定です。ブラウザーの言語設定や以前の言語Cookieで他言語へ切り替わることはありません。管理キーを画面へ埋め戻したり、ブラウザーの認証情報ストレージへ保存したりしません。ペア設定と確認操作はJavaScriptなしでも使えます。

HTTPSはゲートウェイまたはリバースプロキシで終端します。ゲートウェイは技術上、転送するヘッダーやタスク内容を読み取れるため、信頼できるサーバーを使用してください。ロック画面の認証情報はスマホ側で扱います。結果が不明な要求を自動で再送する機能はありません。

## 開発用コマンド

Go 1.23以降が必要です。配備にはサポート中のツールチェーンを使用してください。Dockerのビルド環境と依存チェックサムは固定しています。このディレクトリで実行します。

```sh
go test -race ./...
go vet ./...
go build -trimpath -o mika-relay .
```

リポジトリのルートから実行する結合検査:

```sh
./gradlew :core:test :app:testDebugUnitTest :core:cliTest :core:relayTest
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest -PdevInstall
```

`relayTest` は実際のGoゲートウェイ、本番用Kotlinトンネルとスマホ認証、Python CLI/MCPを接続し、共通タスク、トークン更新、USB専用トークンの拒否、ペア解除を検査します。検査用HTTP接続はループバックだけに限定され、Androidの接続先はHTTPSのみです。通常のJVMテストにはGoは不要です。公開証明書、待機中の動作、Wi-Fiとモバイル回線の切り替えは、配備先・実機で別に確認します。
