# 中国向け求人の検索条件コード

BOSS直聘の上流資料に含まれる公開条件表（/wapi/zpgeek/search/job/condition.json）の記録。現在も有効か実際の表示や応答で確認する。日本の学歴・給与・就業条件へ自動換算しない。以下のコードはアプリの識別値であり変更しない。

## 職務経験（experience=）

| 条件 | コード |
|---|---|
| 在学中 | 108 |
| 新卒 | 102 |
| 経験不問 | 101 |
| 1年未満 | 103 |
| 1〜3年 | 104 |
| 3〜5年 | 105 |
| 5〜10年 | 106 |
| 10年以上 | 107 |

## 給与表示（salary=）

| 画面上の区分 | コード |
|---|---|
| 3K未満 | 402 |
| 3〜5K | 403 |
| 5〜10K | 404 |
| 10〜20K | 405 |
| 20〜50K | 406 |
| 50K以上 | 407 |

Kの意味、通貨、支給回数は求人本文で確認し、円や日本の年収と同一視しない。

## 資金調達

未調達=801、エンジェル=802、A=803、B=804、C=805、D以降=806、上場済み=807、調達不要=808。

## 就業区分・精算・時間帯

全職=1901、兼職=1903。
日払い=2501、週払い=2502、月払い=2503、作業完了時=2504。
週末・祝日=2701、夏冬休み=2702、短期=2703、長期=2704、平日=2705、夜勤=2706。

URLのパラメータ名を記していない区分は、上流資料でもURL上での確認がない。パラメータを推測して送信しない。「指定なし」の0は該当パラメータを付けない。
