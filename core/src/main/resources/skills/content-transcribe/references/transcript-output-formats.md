# 要約と文字稿の形式

時刻は「分:秒」、1時間を超える場合は「時:分:秒」。推定の場合は「約」と明記する。原文にない時刻を補わない。

## 要約
5〜10文でテーマ、主要な論点、結論をまとめる。感想や評価を事実に混ぜない。

## 章立て
1行に時刻と短い見出しを書く。例:
00:00 導入とテーマ
03:40 背景と課題
09:15 二つの方法の比較
21:30 実際のデータ
35:05 質疑応答

## 章ごとの要約
時刻と見出しの下に、その章で実際に述べられた内容を2〜3文で書く。推定の長さは「約5分」のように区別する。

## 引用
原文を正確に写して、対応する時刻を示す。字幕原文か日本語訳かを明記する。引用の省略で意味を変えない。

## 記事案
題名、出典を示す導入、主なテーマごとの節、時刻付きの引用、要点の順に構成する。資料にない事実や提案を原著者の主張として追加しない。
