## 開始条件
読む、下書きする、送る、のどれが依頼されているかを分ける。ユーザー指定のアプリとアカウントを使う。LINEの連絡先やグループ、Gmailの宛先を推測しない。

## 手順
1. 会話一覧や受信トレイから対象を探し、本文を開く。必要な範囲を時刻・送信者・添付とともに読む。未読数と会話本文を混同しない。
2. 宛先は表示名、プロフィール、グループ名、実際のメールアドレスで照合する。同名が複数あれば確認する。
3. 下書きだけの依頼なら案を提示して終了する。送信依頼なら既存の確認モードと承認範囲を適用する。
4. 送信直前に宛先と本文全体、添付ファイルを照合する。既存の未送信文を消したり、別アカウントへ切り替えたりしない。
5. 送信後は会話の該当メッセージ、またはメールの送信済みを読む。

## 注意点
入力欄が空になっただけでは送信成功とはいえない。通信待ちや失敗表示を確認し、重複送信を避ける。Enterで送信される設定もあるため、改行入力を送信と取り違えない。一覧のプレビューは本文全文ではない。

## 完了の確認
読む依頼の要約は実際の本文と時刻に対応する。送信依頼は、正しい宛先に正しい内容が送信済みであることを操作後に確認できる。

## ユーザーに引き継ぐ条件
ログイン、認証コード、本人確認、同名の宛先など本人の判断が必要な場合。
