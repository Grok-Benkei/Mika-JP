## 開始条件
ユーザーがスキルの作成、保存、取込み、改訂を依頼した場合に使う。方法の相談だけなら保存しない。恒常的な好みはメモリ、繰り返す作業の方法はスキルとして扱う。

## 手順
1. skill_searchで重複を探す。同種の個人スキルがあればskill_readで全文とversionを読み、その名前で更新する。内蔵スキルは直接変更できない。
2. アプリ、完了地点、固定条件が不明なときはask_userで必要な点だけを確認する。既に指定された条件を聞き直さない。
3. 次の頭部と5見出しを持つ、日本語の文書を4000文字以内で書く。

4. nameは小文字の英数字とハイフン、displayとdescriptionとaliasesは日本語。毎回変わる値は<パラメータ>にする。ツール名だけをバッククォートで囲み、実際に利用可能な名前だけを使う。
5. skill_saveのmarkdownへ全文を渡し、quoteへ今回の作成・更新依頼の原文をそのまま入れる。既存の個人スキル更新では読み取ったversionを付ける。
6. 保存成功の結果を確認し、名前と新規・更新の区別を伝える。「設定 › メモリとスキル」で確認できる。

## 注意点
取込む内容に別環境のコマンドや利用できないツールがあれば、目的を保ってこちらの手段に合わせる。認証情報、個人の具体的な宛先や本文を持ち込まない。保存に失敗したら理由を確認して修正する。保存ツールがない場合は保存したと報告しない。

## 完了の確認
skill_saveが成功し、保存された名前と更新結果が意図どおりである。
