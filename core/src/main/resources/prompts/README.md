# プロンプトの構成

Mika JPのモデル向け指示を管理する。システム指示、能力とツールの説明、会話、学習内容、検証理由は日本語で記述する。ユーザーの入力言語や端末の言語にかかわらず、人が読む説明、質問、タイトル、メモリ、スキルは日本語にする。コードから埋め込む{{name}}のキー、ツール名、JSONキーと列挙値は翻訳しない。

- system/: アシスタントの役割と一般原則。日本向けの方針はidentity.md。
- capabilities/: そのタスクで利用できる能力の説明。能力のないタスクには注入しない。
- tools/: 各ツールの詳細。識別子と説明ファイルを1対1に保つ。
- entries/: 能力グループを展開する前に使う短い入口説明。
- feedback/: ツールとループの結果をモデルへ伝えるテンプレート。##の後のキーはコードの契約。
- roles/: タイトル作成、読画、位置特定、意図判定、検証、学習などの内部役割。

日本語化では、画面の原文を示すラベルや引用、URL、ファイル名、識別値を改変しない。日本語の見出しへ変更した学習スキルはSkillDrafterの検証規則と一致させる。既存の個人スキルの見出しも互換性のため受け付ける。

変更後はPromptLayoutTestで構造と埋込み変数を確認し、PromptSurfaceTestとLoopScenarioTestの差分をレビューする。スナップショットは差分の意味を確認してから更新する。
