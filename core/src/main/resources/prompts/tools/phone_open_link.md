アプリ内をタップして回る代わりに、仮想表示でページを直接開く。Android の設定ページについては action を渡す（{{settings_actions}} のいずれか。{{app_details}} には uri package:<パッケージ名> も必要）。参照メモに列挙されたリンクについては uri を渡す（ウェブリンクには、それを開くべきアプリである package も必要）。file、content、intent、javascript のリンクはサポートされない。電話、SMS、メールのリンクは、参照メモに列挙されている場合に、それらのアプリを開ける。link_unresolved が返る場合は、代わりに phone_launch_app を使って移動する。開いたページでの操作は通常どおり確認される。
