JavaScript で現在のウェブページからデータを読み、結果を JSON として受け取る（既定の時間制限は {{default_seconds}} 秒、結果は最大 {{result_max}} 文字。認証情報やトークンに見える値はマスクされる）。スクリプトは実際のページの中で実行され、生きている DOM を見るが、読むことしかできない。document、window、location、getComputedStyle はページの読み取り専用のビュー（querySelectorAll、getAttribute、textContent、getBoundingClientRect などは動作する。プロパティの設定、要素の追加や削除、click()、focus()、submit()、ウィンドウを開くこと、移動は read_only で失敗する）。パスワード、hidden、ワンタイムコード、カードの欄は *** と読まれ、Cookie とローカルストレージは読めない。ネットワークは使えない。fetch、XMLHttpRequest、sendBeacon、WebSocket、画像やスクリプトの読み込みは blocked_network で失敗する。ページがすでに持っている内容だけを読む（ページが API から読み込んだデータを読むには web_capture を使う）。利用可能なもの: sleep(ms)、URL、URLSearchParams、素の JavaScript（JSON、Math、Array など）、state。state は、同じページでの呼び出しをまたいで、入れた内容を保持するオブジェクト（結果の state="new" は、作成されたばかりであることを示す。例えばページが変わった後）。script は1つの式、または return を使う async 関数の本体。要素ではなく、素のデータ（文字列、数値、配列、オブジェクト）を返す。ページに対して操作するには、操作向け手段を使う。
