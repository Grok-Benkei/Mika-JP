作業ディレクトリを /workspace として、Linux の実行環境（Alpine、/bin/sh -lc）でシェルコマンドを実行する。exitCode、timedOut、durationMs、出力（長い場合は先頭と末尾。その場合 fullOutputPath に全体がある）、ネットワークが有効かどうかを返す。ok が true になるのは、終了コードが0でタイムアウトしなかった場合だけ。`mika phone <op> '<json-args>'` は、現在の作業のスマートフォン向け手段を通常の実行経路で呼び出す。例: `mika phone query '{"text":"設定"}'` または `mika phone run '[{"op":"tap","targetText":"設定"}]'`。簡単な作業では、シェルを起動しないよう、直接の手段を使う。
