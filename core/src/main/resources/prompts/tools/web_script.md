現在のウェブページに対して JavaScript プログラムを実行し、繰り返しの複数手順の作業を1回の呼び出しで行う。多くの一覧項目を読む、結果をページごとにめくる、複数の欄に入力するなど。単一の操作には使わない。その場合は web_tap/web_type_text を使う。code は async 関数の本体。JSON に変換できる値を返す。スクリプトには DOM がない。document、window、location、fetch、その他すべてのブラウザのグローバルは未定義。素の JavaScript（Math、JSON、Array など）と `mika` だけがあり、mika が返すものはすべて素のデータ（常に await する）。mika.snapshot() → {snapshotId, elements:[{ref, role, name, center}]}、mika.read({maxChars, offset}) → ページ文面の断片 {text, nextOffset}、mika.queryAll(cssSelector, {fields: ['text','attrs','value','box'], limit, maxChars}) → {items:[{tag, text, attrs, value, box}], total}、mika.query(cssSelector, opts) → 最初の項目または null（fields が ['count'] の場合は数値）、mika.text(cssSelector) → 見える文面（パスワードに似た値は *** と読まれる）、mika.tap(ref)、mika.type(ref, text, {enter})、mika.scroll('down'|'up'|'left'|'right', {amount})、mika.navigate(url)、mika.wait(ms) または mika.wait({text, timeoutMs}) → true/false、mika.log(...)。tap/type は、スクリプト内の最新の mika.snapshot() の ref を使う。各操作は、通常の呼び出しと同じ実行と記録の経路を通る。送信、投稿、注文、削除、支払いを含む。失敗した mika 呼び出しは、エラーコードで始まるメッセージを持つ Error を投げる。制限: 操作 {{max_actions}} 回、読み取り {{max_reads}} 回、{{max_seconds}} 秒。新しいページを読み込む移動でスクリプトは終了する（endedBy=navigation）。result（JSON）、logs、各結果を伴う actions を返す。その後に操作する前に web_observe を呼び出す。ページが変わっている場合がある。
