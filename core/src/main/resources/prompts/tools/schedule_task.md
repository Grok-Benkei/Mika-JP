このユーザーの予約作業を作成または管理する。op=list で既存の計画を確認してから変更する。一時停止、再開、削除、run_now、再予約には、その triggerId を使う。op=create（既定）では、ユーザーが後で何かをするよう求めた場合にだけ、将来の作業を予約する。固定のリマインダーについては、reminder に正確なメッセージを、goal にその短い説明を設定する。これはモデルを実行せずに配信する。アプリやウェブの操作が必要な作業については、reminder を省く。1回限りまたは固定間隔の開始には at を使う。毎日／毎週の現地の時計時刻には、夏時間の変更で時計時刻がずれないよう、repeatAt を repeatZone と任意の weekdays とともに使う。条件は、まず読み取り専用のウェブと実行環境の手段で確認される。条件が満たされた場合にだけ作業が実行される。ユーザーがその時刻の後に空き時間まで待ちたい場合は whenIdle を設定する。この手段が成功するまで、将来の作業が手配されたとは主張しない。
