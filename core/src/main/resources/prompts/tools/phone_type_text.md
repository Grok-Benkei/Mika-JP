文面全体を、フォーカスされた欄へ1回の呼び出しで入力する。まずその欄をタップし、ref+snapshotId を渡して対象にするか、element にその欄を示す（列挙されたままのラベル、アクセシブル名、プレースホルダー。現在の表示にある入力欄のうち、正確に1つに一致しなければならない。そうでない場合、結果にはどれが一致したかが示されるか、確認を求められる。部分一致は resolvedFrom と matched として報告される）。pressEnter は、文面が入力された後に送信する。結果の effect がその欄を読み直す。readback はその欄が今示している内容（パスワード欄では隠される）、readbackMatches は意図した文面かどうか。到達しなかった文面は自動で1回再試行される。effect.kind は、他の操作と同様に done、small_change、no_effect、place_changed。要素一覧で読めない状態（アプリが自分で描画している場合）では、ref の代わりに入力欄の座標を渡す。x+y（visibleText の中心）または phone_find_visually の @vN ref。その座標がタップされ、文面がそこの入力欄に貼り付けられ、キーボードの表示にかかわらず、表示の文面で確認される。確認が一致すれば入力されたことになる。point_not_typed は、その座標が文面を受け付けなかったことを示す。繰り返さず、入力欄を再度探す。ref も座標もない場合、文面はフォーカスを持つ入力欄へ同様に入る。no_focus は、入力欄の座標を渡すことを示す。座標がない場合は、element に数語で入力欄を示す（例: 一番下のメッセージ入力欄）。要素一覧でこの状態が読めず、一致する欄がない場合、その入力欄は視覚的に探され（phone_find_visually の確認を伴う）、その座標で同様に入力される。foundBySight と seen に何が使われたかが示される。
