スマートフォンの現在の状態（仮想表示）を確認する。前景のアプリ、見えるすべての要素、ウィンドウごとにまとめたアクセシビリティツリー全体を、親子関係と操作要素の状態とともに返す。ツリーで、どの項目やダイアログが操作要素を持つかを特定し、その操作要素の ref と snapshotId を {{tap}} に渡す。ツリーが表示の多くを欠いている場合、treeQuality がその旨を示し、visibleText がタップ中心を伴う端末上の OCR 文面を追加する（画像を見られる場合は画像も）。対象がまだ見つからない場合やあいまいな場合は、{{screenshot}} または {{find_visually}} を求める。
