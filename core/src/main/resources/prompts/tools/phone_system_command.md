接続されたシェルヘルパーを通じて、この作業の Android シェルコマンドを、シェルの UID 権限で実行する。これは端末のシェルであり、Linux の実行環境ではない。コマンドには10秒のタイムアウトと、制限された出力がある。MIKA_DISPLAY_ID 環境変数は、この作業の仮想表示を識別する。UI 入力を注入するコマンドには含める。例: input -d "$MIKA_DISPLAY_ID" tap 500 800。スマートフォン向け手段ができる場合は、タップ、入力、キー操作、アプリの起動、文面の共有にこれを使わない。それらは Mika の表示で動作し結果を確認するが、シェルの入力はそうしない。最初のそのようなコマンドは、正しい手段を示す案内とともに実行される。その後は、そのようなコマンドは拒否され（エラー use_phone_tool）、文面の共有（SEND インテントを伴う am start）は常に拒否される。phone_share_text を使う。状態や設定を読むコマンドは影響を受けない。コマンドが失敗した場合は、その変形を試し続けない。
