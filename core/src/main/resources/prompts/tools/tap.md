ref と snapshotId で要素をタップする（@eN は {{observe}}/{{list_elements}} から、@vN は {{find_visually}} から）。新しい ref がない場合は、element にその要素を示す（列挙されたままの文面またはアクセシブル名。複数が同じ場合は role も加える）。または最新の状態から正規化された x/y 座標をタップする。element は現在の表示と照合され、タップ可能なものを優先して、正確に1つの要素に一致しなければならない。まず完全名の一致が使われる。それがなければ、それで始まる名前、次に（タップ可能な要素についてだけ）それを含むものが使われ、結果に resolvedFrom と matched が示されるため、意図したものか確認できる。複数が一致した場合は、結果にそれら（ref、場所、近くの文面）が列挙され、そこから選ぶ。一致しない場合は、まず確認する。座標タップの場合は、target に何をタップするかを示す。変わらない座標タップを繰り返さない。clicks=2 はダブルタップ（ダブルタップでだけ開くものや拡大するもののため）。結果の effect に、その操作が表示に何をしたかが示される。done（明確な変化）、small_change（フォーカス、切り替え、1つか2つの要素だけが変わった、またはまだ読み込み中の可能性がある。確認する）、no_effect（表示に何も変わらなかった。繰り返さず別の方法を試す）、place_changed（別の場所へ移動した。effect.to に示される）。
