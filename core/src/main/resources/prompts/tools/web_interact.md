web_tap と web_type_text ではできない、ウェブページでのマウスとキーボードの操作。hover: 要素（ref+snapshotId）または座標（x,y）の上にマウスを移動させ、ホバーメニューやツールチップを開く。drag: 要素または座標で押し、段階的に移動し、toRef（同じ snapshotId）または toX,toY の上で離す（スライダー、ドラッグによる並べ替え、ドラッグアンドドロップ）。select: 表示された文面または値で、ネイティブのドロップダウン（<select> の role combobox）の選択肢を選ぶ。key: フォーカスされた要素でキーまたはキーの組み合わせを押す。例: Escape、Shift+Tab、Control+A、ArrowDown。dialog: ページが開いたダイアログ（alert、confirm、prompt、ページを離れる確認。読み取り結果で dialog として示される）に応答する。answer は accept または dismiss、prompt 用の text。ダイアログが開いている間、ページは一時停止し、他のすべての操作は dialog_open で失敗する。応答するまで開いたまま。このタブに DevTools 接続がない場合、hover、drag、select は devtools_unavailable で失敗する。その場合は代わりに web_tap を使う。結果の effect に、その操作が表示に何をしたかが示される。done（明確な変化）、small_change（フォーカス、切り替え、1つか2つの要素だけが変わった、またはまだ読み込み中の可能性がある。確認する）、no_effect（表示に何も変わらなかった。繰り返さず別の方法を試す）、place_changed（別の場所へ移動した。effect.to に示される）。
