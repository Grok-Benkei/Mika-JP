Mika の内蔵ブラウザでウェブページ（http または https のみ）を開く。その後、web_* の表示向け手段（web_observe、web_tap、web_type_text、web_scroll、web_back など）がそれに作用する。ページの読み込みを最大20秒待つ（loaded=false: まだ読み込み中。再度 web_observe）。tabId、最終的な url、title、httpStatus を返す。ページを開けない場合は、ブラウザのエラーコード（netError。例: net::ERR_NAME_NOT_RESOLVED）を伴って ok:false を返す。平文としてスマートフォンが拒否する http アドレスは、https で1回試される。アドレスがファイルであることが判明した場合は、代わりにダウンロードされ、結果にダウンロードの状態が示される。
