情報が不足している場合や、選択がユーザーに委ねられる場合にユーザーへ質問する。答えが短い選択肢のいずれか（2〜5個）の場合は、必ず options として渡す。ユーザーがタップするボタンとして表示される。メッセージ文や最終回答の中にそれらの選択肢を列挙しない。自由回答の質問の場合にだけ options を省く。パスワードや確認パズルはここでは尋ねない。それらは hand_to_user の対象であり、手段でその手順を進められない場合にだけ使う。結果にはユーザーの答えが入る。時間内に答えが来ない場合はエラー no_answer が返る。これは答えではない。最も妥当な解釈で続行し、その旨を返信で伝えるか、答えがなければ作業を続けられない場合は end_not_done で終える。
