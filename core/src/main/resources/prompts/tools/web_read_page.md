表示に収まる範囲に限らず、ウェブページの読める文面全体を読む。まず開いているダイアログ（<<dialog>> と <<end of dialog>> の間）、次に本文（見出しには # が付く）、さらにリンク最大50件と画像最大20件。ナビゲーション、フッター、その他のリンク一覧のブロックは、それぞれ1行の <<collapsed …>> にまとめられる。unfold=true を渡すと全文が得られる。長いページは分割して返る。同じ unfold で、nextOffset を offset として渡して続きを読む。url なしの場合は現在のタブを読む。url ありの場合は、そのアドレスを一時的なバックグラウンドタブで読み、現在のタブはそのままにする。
結果には読み取りの経過が示される。chars、textDensity（リンク文面でない文面の割合）、verdict: ok、thin（文面が少ない。まだ読み込み中、または内容は別の場所にある）、needs_sign_in（内容の前にサインインフォームがある）、refused（確認、拒否、HTTP エラーのページ）、image_text（内容のほとんどが画像や描画であり、文面だけでは捉えられない）。ページが宣言している場合は published と updated が現れる。
