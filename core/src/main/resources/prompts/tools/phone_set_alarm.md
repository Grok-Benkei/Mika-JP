表示を開かずに、標準の Android のアラームアクションでスマートフォンの時計アプリにアラームを設定する。アラームごとに1回呼び出す（複数のアラームについては、時刻ごとに1回ずつ呼び出す）。時刻は24時間制の現地の時と分。days でそれらの曜日に繰り返す。結果には、どのアプリが受け付けたか（handledBy）と check が示される。verified は、システムがこれを次のアラームとして今報告しているため、設定されていることを示す。earlier_alarm_first は、より早いアラームが先にあるため、ここからは確認できないことを示す。not_seen または unknown は、確認できなかったことを示す。ユーザーが確実さを求め、check が verified でない場合にだけ、phone_show_alarms を1回呼び、一覧を確認する。not_supported が返る場合は、代わりに時計アプリ自体の状態でアラームを設定する。これはスマートフォンのアラームであり、schedule_task は Mika 独自の予約作業やリマインダー用。
