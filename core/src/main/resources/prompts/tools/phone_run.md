操作の前に、各対象を現在のアクセシビリティツリーで再度特定しながら、スマートフォンのコマンド列をローカルで実行する。次の状態を、モデルによる新たな判断なしに、明確な条件やラベルで扱える場合に使う。コマンド: launch(packageName、任意で cold)、tap(targetText/resourceId/role または x+y)、type(text、任意で targetText/resourceId/role と pressEnter)、clear(任意で対象)、scroll(direction、amount)、swipe(startX、startY、endX、endY、durationMs)、key(key)、back、wait(targetText、present、timeoutMs)、assert(targetText、present)、observe。コマンドに whenText を追加すると、実行前にその文面が見えていることを必須にできる。対象が見つからない場合やあいまいな場合、条件が満たされない場合、操作が失敗した場合、アプリが切り替わった場合、視覚的な確認が必要な場合は止まる。実際のスマートフォンの操作は通常の実行経路を通り、記録される。最後の状態を読み、必要であれば別の呼び出しで続ける。長い一覧やチャット履歴を集めるには phone_collect を使う。
