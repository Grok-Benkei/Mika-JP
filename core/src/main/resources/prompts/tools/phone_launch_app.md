正確なパッケージ名で、スマートフォンの仮想表示にインストール済みアプリを開き、前景に来るまで待つ。アプリの別の複製（複製アプリや仕事用プロファイルの複製）を開くには、その複製の phone_list_apps の項目の user も渡す。メインのアプリについては省く。cold=true にすると、初期状態から再起動する。アプリが前景に来ない場合は、代わりにそこにあるものを ok:false で返す。前景にあるがそのウィンドウを読めない場合は、結果にその旨が示される。再度起動しない。システムがどちらを開くか尋ねる場合（メインと複製として2回インストールされたアプリ）は、chooser を伴って ok:true を返す。ユーザーが意図した選択肢をタップし、そうでなければメインのものをタップする。再度起動しない。別の作業がそのアプリを使っている場合は app_in_use_by_other_task を返す。何か他のことをする代わりに待ちたい場合は、wait（秒）を付けて再度呼び出す。他の作業が手放すと直ちにアプリを開く。
