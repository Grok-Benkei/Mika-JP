文面全体を、フォーカスされた欄へ1回の呼び出しで入力する。まずその欄をタップし、ref+snapshotId を渡して対象にするか、element にその欄を示す（列挙されたままのラベル、アクセシブル名、プレースホルダー。現在の表示にある入力欄のうち、正確に1つに一致しなければならない。そうでない場合、結果にはどれが一致したかが示されるか、確認を求められる。部分一致は resolvedFrom と matched として報告される）。pressEnter は、文面が入力された後に送信する。結果の effect がその欄を読み直す。readback はその欄が今示している内容（パスワード欄では隠される）、readbackMatches は意図した文面かどうか。到達しなかった文面は自動で1回再試行される。effect.kind は、他の操作と同様に done、small_change、no_effect、place_changed。
