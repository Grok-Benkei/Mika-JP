# 原作Mikaの参考資料

Mika JPは、Wang Zan氏が開発した[Mika](https://github.com/wangzan101/Mika)を元にした日本向けフォークです。現在の機能、対応環境、導入方法は[日本語のREADME](README.md)を参照してください。公開APKは[Mika JPのリリース](https://github.com/yebisu0529-ship-it/Mika-JP/releases)から入手できます。

このページは上流資料への参照をまとめたものです。元の開発履歴、著作権表示、ライセンスは保持しています。上流の説明文やデモを確認する場合は上の原資料を参照してください。リポジトリ内の画像・動画ファイルも削除していません。

## 日本語版との違い

上流の画面例や動画には中国語などの表示や、上流MikaのアプリIDを使った手順があります。それらは原作の資料であり、Mika JPで同じ操作を実機確認した記録ではありません。上流のAPKもMika JPとは別のアプリです。

Mika JPの画面とAIによる説明は日本語に固定しています。導入は[日本語の導入ガイド](docs/setup-guide.ja.md)、日本向けの変更と確認範囲は[調整記録](docs/JAPAN_TUNING.md)を参照してください。
